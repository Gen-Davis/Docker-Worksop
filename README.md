# NYC Taxi Data Pipeline

## Project Overview

This project is a data engineering pipeline built using the NYC Taxi dataset. 
The pipeline demonstrates how to ingest, store, and orchestrate data using 
Python, Pandas, PostgreSQL, Docker, and Kestra.

## Technologies Used

- Python
- Pandas
- PostgreSQL
- Docker
- Kestra
- SQL
- GitHub

## What I Practiced

- Downloading and ingesting NYC Taxi trip data
- Processing data using Python and Pandas
- Loading data into PostgreSQL
- Running PostgreSQL inside Docker containers
- Writing SQL queries for data exploration
- Using Kestra for workflow orchestration
- Managing a data engineering project with Git and GitHub
